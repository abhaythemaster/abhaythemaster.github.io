Built By Me

Projects & Mods

Launchers, performance mods, and tools built for the Minecraft community.

Masterix

Launcher · Android

A full Minecraft: Java Edition runtime built for Android — custom JVM bridge, Forge/Fabric/Quilt loader support, and a GPU-tuned render pipeline for mobile hardware. Feature-rich and heavily optimized for performance.

Masteron

Optimization Mod

A rewritten chunk-rendering pipeline with frustum culling and batched draw calls — Sodium/Vulkan-mod-class FPS gains, built entirely in-house with a long list of inbuilt tuning features.

MasterZ

P2P Networking

A peer-to-peer virtual LAN system with built-in NAT traversal — join a friend's LAN world over the internet directly, no shared network and no port forwarding required.

DiscordMC

Discord Integration

Embeds Discord text and voice directly into the Minecraft client via an in-game RPC bridge — talk to anyone on your server without ever alt-tabbing out.

MasterX

Creator Tools

A cinematic utility mod built for thumbnail and machinima work — spawn, reposition, resize, and re-skin NPCs, and inject custom entities on demand.

MasterzSkins

Cosmetic Mod

An in-game skin and cape switcher with 50+ built-in capes, local skin file loading, and live player-model tweaks — no client restart needed.

AbhayOne

Texture Pack

An all-in-one PvP-focused resource pack — enhanced sword and item textures, reduced shield and fire opacity, plus a custom antialiasing/frame-blending filter for smoother motion clarity.
